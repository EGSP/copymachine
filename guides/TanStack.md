# TanStack Start, Query 
## Серверные функции в компонентах
Получение данных:
- Используй query вместо прямого вызова серверных функций.
- Используй объект результата вместо разворачивание его свойств. Дай имя, например plansQuery.

Изменение данных:
- Используй mutation вместо прямого вызова серверных функций.
- Связывай mutation и query, если между ними есть логическая связь.
Например, plansAddMutation должна обновить plansQuery.
- Всегда задавай мутациям ключ.
- Если серверная функция возвращает значение - используй setQueryData.


**Всё что не следует правилам выше - старайся отрефакторить.**
