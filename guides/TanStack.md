# TanStack Start, Query

Данные с бэкенда (Express) запрашивай через **axios** (`apiClient` в `#/lib/api`): вызовы пиши **прямо в теле** `queryFn` / `mutationFn` внутри хуков в `#/lib/queries/*` (`use*Query`, `use*Mutation`). Не используй для этого серверные функции TanStack Start.

## Запросы в компонентах

Получение данных:

- Используй query вместо прямого вызова API.
- Предпочитай готовые хуки из `#/lib/queries/…` вместо inline `useQuery`.
- Используй объект результата вместо разворачивания его свойств. Дай имя, например plansQuery.

Изменение данных:

- Используй mutation вместо прямого вызова API (в т.ч. разовые действия вроде выбора пути — см. `usePathPickMutation`).
- Предпочитай хуки `use*Mutation` из `#/lib/queries/…`.
- Связывай mutation и query, если между ними есть логическая связь.
  Например, создание плана должно инвалидировать список планов.
- Всегда задавай мутациям ключ.
- Если запрос к API возвращает значение для кэша — используй `setQueryData` при необходимости.

**Всё что не следует правилам выше — старайся отрефакторить.**
